# WriteWise — 自配 API Key 的 Chrome 写作助手

可直接加载的 Manifest V3 插件，无需构建或订阅。支持语法、拼写、标点、清晰度、语气、改写、精简、翻译，以及独立写作台中的草稿、大纲与头脑风暴。

## 安装（约两分钟）

1. 打开 Chrome，地址栏输入 `chrome://extensions`。
2. 打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本文件所在的 **writewise 文件夹**（含 manifest.json）。如果拿到 ZIP，请先解压。
4. 在 Chrome 工具栏扩展菜单中固定 WriteWise，点击图标 →「API 与偏好设置」。
5. 填写 API Base URL 与 API Key，点击「获取 / 刷新模型」并授权 API 域名。插件自动读取此 Key 可见的模型列表，可搜索并选择；已授权域名在修改地址或 Key 后会自动重新获取。选择模型后点击「保存并授权 API 地址」，再点击「测试已保存的连接」。请勿把 Key 粘贴到聊天或网页输入框。
6. 刷新已经打开的网页。直接在输入框中写作，停顿后自动给问题文字画线；鼠标悬停查看修改预览与解释，点击「应用修改」或「忽略」。无需点击 W 或打开面板。

API Key 需要来自 API 服务商控制台；ChatGPT / Grammarly 等网页产品的会员通常不等于 API 额度。插件不内置使用次数限制，仍受你所用 API 的余额、限流和模型能力限制。

## 服务商配置

| 服务商 | API Base URL | 模型 |
| --- | --- | --- |
| OpenAI | `https://api.openai.com/v1` | 从控制台填写你可使用的模型 ID |
| DeepSeek | `https://api.deepseek.com/v1` | 例如 `deepseek-chat`，以服务商当前支持为准 |
| 通义千问 / 百炼 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | 例如 `qwen-plus`，注意账号地域 |
| 自建 OpenAI 兼容网关 | 你自己的 HTTPS Base URL | 对应模型 ID |
| Ollama | `http://localhost:11434/v1` | 本机已下载、擅长 JSON 输出的模型 ID；Key 可填 `ollama` |

也可以填写完整的 `/chat/completions` URL。只支持 HTTPS；本机 `localhost` / `127.0.0.1` 可用 HTTP。若本地服务拒绝 Chrome 扩展 Origin，请按该服务的文档为本插件 Origin 添加允许规则。服务端重定向被禁用，避免认证头被转发；请直接填写最终接口地址。

模型发现使用同一 Base URL 下的 `GET /models`，携带你当前填写的 Key，不要求先保存或预填模型 ID。首次访问新域名需要点击按钮完成 Chrome 授权，之后输入停顿约 700 毫秒会自动获取。列表去重排序并保留当前选择；切换地址或 Key 会清空旧列表，过时请求不会覆盖新结果。获取模型不会自动保存 Key 或切换已保存的模型。

`/models` 列表可能包含图像、语音、向量等非对话模型；接口通常不提供足够的能力元数据，所以不会擅自过滤或声称所有模型均能用于写作。请选择支持文字 Chat Completions 的模型，并测试连接。服务商不支持列出模型、列表为空或 Key 无权限时会显示原因，也可手动填写模型 ID。

使用 Chat Completions 协议。纠错与写作使用 JSON 指令；翻译使用短提示词和纯文本流式输出。不强依赖 `response_format`、temperature 或特定 token 参数，便于接入不同服务商。API 形状参考 [OpenAI 官方文档](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)。部分模型不能稳定输出 JSON，会显示明确错误而不会替换原文。API 地址与模型权限需自行确认。

## 使用

- **行内校对**：默认开启。聚焦 textarea、普通文字 input 或常规 contenteditable 编辑器后，停顿约 0.65 秒开始请求。语法、拼写、标点使用红色下划线，清晰度与语气使用蓝色下划线。悬停问题文字即可查看原文 → 建议、解释，并直接应用或忽略；普通输入与选区不会被标记层拦截。也可用 Tab 聚焦标记查看建议、Escape 关闭。
- **扩展面板**：W 按钮作为可选入口，保留润色、翻译、全文预览、复制和撤销等功能，不是行内校对的前置步骤。
- **W 悬浮件**：W 按住即可拖动到不遮挡文字的位置；拖动不会打开面板，轻点仍可打开助手。位置只在当前页面会话中保留，输入框切换后会重新贴近输入框。
- **滚动时保持结果**：页面上下滚动不会关闭选区工具条、翻译结果或问 AI 卡片；点击页面其他位置、关闭按钮或 Escape 才会关闭。W 被手动拖动后，即使输入框暂时滚出视口也会保留在窗口内。
- **句内修改预览**：悬停时淡粉色高亮当前句子，悬浮卡保留句子上下文；被删除的词用红色删除线，新词用蓝色显示，未变的文字保留原色。支持中英混排与一条建议中多处词语的对比，不包含下一行日志或无关段落。点击「应用修改」仅替换本条建议，不重写整段文字。
- **选区检查**：在输入框中选中一段文字，点击 W，或使用右键「用 WriteWise 检查选中文字」。非编辑区选中文字也可检查与复制结果，不会修改网页正文。
- **快捷键**：`Alt + Shift + W`，Mac 为 `Option + Shift + W`。若系统占用，可在 `chrome://extensions/shortcuts` 修改。
- **自动检查**：默认开启，可在设置中关闭。至少 3 个字符，每个输入框两次检查至少相隔 1.8 秒；触发间隔可能叠加停顿等待。输入变化时立即移除旧标记，等待新结果；滚动、换行和调整尺寸时重算位置。当前聚焦的输入框为检查目标，不扫描整页所有表单。
- **划词翻译**：在输入框、富文本编辑器或普通网页正文中选中文字，自动出现工具条，点击「翻译」。可在工具条切换目标语言，不改变已保存的偏好。结果支持复制；可编辑区域额外支持替换选区，富文本替换范围内将转为纯文本，外部格式保留。输入变化、滚动、Escape 或关闭卡片会隐藏结果；无 Key 时会明确提示配置。选中本身不会调用翻译 API。也可通过右键「用 WriteWise 翻译选中文字」。
- **独立写作台**：点击插件图标 → 独立写作台。选择「生成草稿 / 生成大纲 / 头脑风暴」等操作。翻译和新草稿使用设置中的目标语言，纠错与改写保留原文语言。支持 `⌘ / Ctrl + Enter`。
- **划词默认语言**：中文默认翻译为英文，英文默认翻译为简体中文，无需先选语言。使用本机字符检测，不增加 API 请求：包含汉字的中英混排（例如中文夹杂技术术语）默认译成英文；无汉字默认译成中文。当前选区仍可手动切换，新选区重新判断。此规则只适用于划词翻译，设置中的语言仍用于独立写作台等其他入口。
- **工具条位置**：鼠标划词后，翻译工具条贴近松开鼠标的位置，正向和反向、多行选区均适用；键盘选区贴近选区活动端的光标。靠近窗口右侧或底部时自动向内避让，译文卡继续跟随工具条。
- **手动移动**：按住工具条左侧 ⠿ 拖动，结果卡一起跟随；支持触屏拖动。也可用 Tab 聚焦手柄后用方向键移动。移动时保留原选区并限制在窗口内；新选区重新出现在鼠标附近，不全局固定位置。
- **复制原文**：工具条的「复制」直接复制选中文字，不调用 AI、不消耗 API 额度，与结果卡中的「复制译文 / 复制回答」分开。
- **问 AI**：选中文字 →「问 AI」，输入问题后发送，或点「解释 / 总结 / 改写」。也支持 Ctrl / ⌘ + Enter 发送。只发送已选文字与本次问题，答案边生成边显示，可复制；不会自动替换选区，不携带整页正文和往次问答。再次提问独立处理，不是多轮聊天。AI 可能出错，请自行核实。问 AI 的模型选择单独记忆。
- **暂停网站**：插件弹窗可暂停当前主机名；设置页可批量维护。暂停后不会发送新的分析请求；已发出的请求无法收回。
- **撤销**：仅保证在内容没有继续变化时撤销最后一次插件替换。富文本中多次修改可优先使用编辑器自己的撤销。

## 检查速度

选区翻译从 1.5 开始边生成边显示，不再等整个译文完成才显示。翻译只请求纯译文，不生成 JSON 包装、总结或修改原因，减少提示词和输出。卡片分别显示当前模型、首字与总耗时；中途关闭会尽力中止请求，尚未完成的译文禁止替换。服务商以 400 / 422 / 501 拒绝流式时会重试普通输出（可能带来额外请求）；直接返回普通 JSON 的兼容服务也可处理。连接中断或输出截断时不会应用部分译文。

## 随任务选择模型

翻译卡、问 AI 卡、网页助手和独立写作台均提供「模型」按钮，可搜索当前 API 返回的模型并即时切换，无需返回设置页。翻译、问 AI、纠错、润色、精简、语气、草稿、大纲与灵感分别记住选择。翻译卡切换后会立即重新翻译，问 AI 切换后重新回答已提交问题，自动纠错下次使用自己的模型；选「跟随默认模型」即可恢复设置页的默认模型。

模型菜单显示该任务中已完成调用的平均首字耗时（翻译）或完成耗时（其他任务），并标记已测模型中最快的一项。未调用模型不宣称速度或质量；不会自动消耗额度对所有模型跑测试，也不会擅自把复杂任务切换到未知模型。快速文字模型适合日常翻译，复杂改写可自行选择质量更好的模型。网络、文本长度与服务负载会影响测量，它不是质量评分。

任务模型与最多 100 条耗时摘要只保存在本机，不保存对应原文；选择按 API 地址与 Key 的摘要关联，换服务商或 Key 后不会误用旧配置。相同模型名的多个服务商不会混用。菜单只返回模型 ID 与耗时，不暴露 Key 或 API 地址。

## 自动校对与缓存

相比早期版本，输入停顿等待由 2.2 秒降到 0.65 秒，连续检查间隔由 8 秒降到 1.8 秒。检查接口只要求返回修改项，在本机重建修改全文，减少模型重复生成原文。超过 4,000 字符的输入框优先检查光标附近最多 4,000 字符；光标附近的标记只代表该范围检查结果，其余内容可通过 W 手动检查（单次上限 16,000 字符）。

后台在内存中缓存最多 30 条结果、有效期 5 分钟，相同请求与相同配置可复用，配置变化或清除 Key 时清空；缓存不写入磁盘。翻译与自动检查分别调度，翻译不必等待自动检查完成。快速切换目标语言会放弃旧翻译结果并尽力中止旧请求，但已发送的请求可能仍被服务商计费。

面板和翻译卡显示 API 请求耗时。0.65 秒是开始请求前的停顿等待，不是保证返回结果的总时间。真实速度仍取决于 API 网络、服务商排队、模型推理和输出长度；可在设置中换用服务商提供的快速文字模型。模拟 API 性能测试仅验证本地调度与请求大小，不代表真实服务商速度。

## 覆盖范围与限制

支持常规输入框与 DOM 富文本，包括许多邮件、社交与办公网页。包含 iframe 中的常规输入框；网站自己的安全策略与编辑器实现可能影响效果。

**不承诺所有网站兼容**：Google Docs 画布、Canvas / PDF 编辑器、封闭 Shadow DOM、某些复杂的协同编辑器、Chrome 内部页面与 Chrome 商店不能直接使用或未验证。Google Docs 等页面建议复制到独立写作台处理。Gmail、LinkedIn 等真实登录网站尚未逐一验收。

单次最多 16,000 字符。全文替换富文本会将目标范围转为纯文本，界面会提示；需要保留格式时优先逐条接受或复制粘贴。替换前核对原文，编辑器拦截替换时提供复制方式。智能建议可能不准确，请预览再接受。

未接入查重数据库，因此**不提供抄袭检测、AI 来源判断、真实文献检索或自动引用验证**。未实现 Grammarly / Superhuman 的跨应用工作流，也不包含团队后台。不会凭模型生成一个所谓可信的检测分数。

## 数据与权限

- API Key 仅保存在 `chrome.storage.local`，关闭同步，限制为扩展受信任上下文可读；网页内容脚本只能读取不含 Key 的必要偏好。Chrome 用户目录不是加密保险箱。
- API 调用仅在扩展后台执行，Key 不进入网页 DOM。不会将完整 API 错误体展示给网页。
- 无统计、广告、遥测、第三方脚本或自建中转服务器。所选服务商仍可能按其政策记录请求。
- 默认自动检查，会发送当前聚焦的受支持输入框文字并产生 API 用量，可在设置中关闭或暂停网站。只发送当前输入框 / 选中文字、写作偏好和补充要求，不发送整页正文。
- 无草稿云同步、无持久化文本历史。写作台保留当前页面内存中的结果，关页清除。
- 排除密码框、只读框、禁用框，以及使用标准 autocomplete 标记的信用卡、支付、验证码字段。无法识别所有未标记的敏感文本；可通过「暂停网站」排除相关站点，开发者也可给区域添加 `data-writewise-ignore`。
- 安装时网页读取权限用于识别输入框；访问自定义 API 域名使用保存时的可选授权。代码不注入主世界，不把 API Key 暴露给页面。

## 本地开发与验证

扩展本身无运行时依赖，直接加载即可。测试需要 Node.js 20+。

```sh
cd writewise
npm test
npm install
npx playwright install chromium
npm run test:browser
npm run package
```

浏览器测试使用本地模拟 API 和真正加载的 Chrome 扩展，检查配置、Key 隔离、语法建议、替换/撤销、原文变化保护、自动画线、悬停应用/忽略、短句、滚动定位、换行与调整尺寸、富文本格式、键盘访问、敏感输入框排除、iframe、写作台、错误反馈与窄屏暗色布局。它不消耗真实 API 额度。无头测试通过临时副本预先授予本地模拟 API 域名权限；真实安装中的可选权限弹窗还需用户实际授权。真实服务商连通性必须在填写自己的 Key 后通过设置页测试。

`npm run package` 在上级目录生成 `writewise-chrome.zip`，不包含 node_modules 或测试产物。图标源生成脚本为 `scripts/icons.mjs`。
