02 · 你的写作偏好

默认开启。停顿约 0.65 秒后开始检查，连续检查至少间隔 1.8 秒，至少 3 个字符。长文本优先检查光标附近最多 4,000 字符，完整内容可通过 W 手动检查。问题文字会画线，鼠标悬停即可预览和应用；选中文字会出现翻译工具条。调用会发送相应文字并消耗 API 额度，可关闭自动检查或暂停网站。

精确匹配主机名，不含协议和路径。例如 mail.google.com。

03 · 保存并开始

保存时 Chrome 会请求访问你填写的 API 域名。检查时只发送当前输入框或选中文字及写作偏好，不上传整张网页。自动排除密码框及标有信用卡、支付信息、验证码自动填充属性的输入框；其他敏感内容请手动避开。
